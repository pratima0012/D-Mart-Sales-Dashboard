## 📌 Project Overview
This project focuses on analyzing D-Mart sales data using Power BI. The dashboard provides valuable insights into sales performance, customer behavior, and product trends to support data-driven decision-making.

---

## 🎯 Objectives
- Analyze overall sales and revenue trends
- Identify top-performing product categories
- Understand customer purchasing patterns
- Evaluate order quantity and profit distribution

---

## 📊 Key Insights
- Sales trends show seasonal variations and growth opportunities
- Certain product categories contribute significantly to total revenue
- Customer purchasing behavior varies across different segments
- Profitability differs based on product category and order size
